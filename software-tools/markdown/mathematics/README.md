## Matrices and Determinants
### Basic matrix
**Markdown**
```markdown
<!-- Basic matrix -->
$$
\begin{matrix}
a & b \\
c & d
\end{matrix}
$$
```

**Rendered Output**
$$
\begin{matrix}
a & b \\
c & d
\end{matrix}
$$

**Markdown**

```markdown
\end{pmatrix}
$$
```
**Rendered Output**
$$
\begin{pmatrix}
